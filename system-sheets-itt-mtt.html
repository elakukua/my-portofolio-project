Google Sheets · ITT · MTT

Monitoring output level through evidence, not assertion.

The Indicator Tracking Table holds what was planned. The Monitoring Tracking Table holds what was recorded, and the evidence behind it. Monitoring at output level means checking those two agree — and that a document exists behind every number.

The reconciliation loop — run every reporting period

03Reconcile both ways
04Evidence check
05Visualise
01

Same spine, both tables

  • Shared indicator code carried identically in ITT and MTT
  • Same period boundaries and same disaggregation labels on both sides
  • One owner per table, so changes are deliberate
  • Without a joinable spine, reconciliation becomes manual cell comparison
02

Validate entry

  • Dropdowns for indicator codes, periods and categories — typing cannot create a new category
  • Totals checked against their own disaggregation
  • Blank achievement against a closed period flagged, not read as zero
  • Error-suppressing formulas removed
03

Reconcile both ways

  • Every ITT indicator and period → is there a matching achievement in the MTT?
  • Every MTT achievement → does it map to a planned indicator and period?
  • One-directional checks miss achievements recorded against unplanned periods, and copy-paste duplication between periods
  • Each discrepancy classified and resolved in a log
04

Evidence check

  • Output-level monitoring means the number is only as good as the document behind it
  • Attendance lists, distribution records, session reports traced per reported figure
  • Means of verification confirmed against what the reference sheet specified
  • Figures without evidence flagged rather than reported
05

Visualise

  • Progress against target, with the gap stated rather than implied
  • A live discrepancy view so unresolved items stay visible
  • Views built per audience: indicator level for field, outcome level for management
