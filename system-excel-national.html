Excel · Microsoft 365 Online

One shared workbook instead of a folder of versioned copies.

National reporting fails predictably: a workbook is emailed out, filled in differently by each team, returned as eleven files that no longer agree. Moving it online removes the failure mode rather than managing it.

How the workbook works — collaborative in place, not emailed around

01One shared workbook
02Clean & harmonise
03Pivot dashboard
04Track delivery
01

One shared workbook

  • Single file on SharePoint with co-authoring — teams enter data in place
  • Sheet protection: each team edits its own range only
  • Data validation on every input cell, so no category is invented mid-entry
  • Input area kept separate from calculation area
02

Clean & harmonise

  • Structured tables so formulas extend as rows are added
  • Lookup-based harmonisation against master lists for location, project, indicator code
  • Consistency checks: totals against disaggregation, missing submissions by team
  • Errors left visible rather than suppressed
03

Pivot dashboard

  • Pivots driven from the analysis layer, refreshing as input fills
  • Slicers for project, period, location, disaggregation
  • A summary sheet readable in under a minute, detail behind it
  • No extra licence needed — the audience can already operate it
04

Track delivery

  • MEAL products per project: due date, owner, status, file location
  • Overdue items surfaced automatically rather than remembered
  • Rolling view by team, so gaps are visible at management level
